-> 📱 Phone Number Location Tracker

-> 📌 Overview
This project tracks the approximate location and service provider of a phone number using Python. It uses geocoding APIs to convert location data into coordinates and visualizes it on an interactive map.

-> 🚀 Features
- Extracts location from phone number
- Identifies telecom service provider
- Converts location into latitude and longitude
- Displays location on an interactive map
- Generates an HTML map file

-> 🛠️ Technologies Used
- Python
- phonenumbers library
- OpenCage Geocoding API
- Folium (for map visualization)
